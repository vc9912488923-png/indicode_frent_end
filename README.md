# indicode
ndiCode is an AI-native programming language built in India. It bridges traditional logic with machine learning, empowering developers and researchers to build high-performance AI and computational biology systems with unmatched efficiency. India’s gift to the global AI era.

## Compiler Front-End Status

As of 2026-11-03, the C++20 compiler front end is estimated at **97% complete** (weighted estimate 97.15%) toward a validated typed representation that can later feed an LLVM backend. The scoped catalogue has 32 of 40 items done, 0 partial, and 8 not started; all 21 CTest cases pass. LLVM is not downloaded, vendored, or built as part of this project. The current implementation includes an owning source manager with indexed line/column mapping, versioned grammar v1.0.0, typed token payloads and preserved trivia, parser/AST recovery, a measured `unique_ptr` AST ownership design with a 10,000-statement stress test, schema-versioned `ast-json` and verified `typed-json` output, stable symbol IDs, a HIR-backed symbol/reference/scope index with revision-based rebuild invalidation, name/type checks, an installable CMake package, records/member access, integer ranges, nested `else if` return paths, checked numeric conversions, static/symbolic tensor shapes, list/index/for-each and named arguments, radix/separator integers, nested block comments, UTF-8 source validation, and source-aware/JSON diagnostics with fix-its. Modules/imports, overloads, generics, effects/ownership checks, incremental parsing, and production readiness remain unfinished. AST/HIR JSON are serialization-only; deserialization and compatibility policies remain future work. The front end remains incomplete.

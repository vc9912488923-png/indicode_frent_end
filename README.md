# indicode
ndiCode is an AI-native programming language built in India. It bridges traditional logic with machine learning, empowering developers and researchers to build high-performance AI and computational biology systems with unmatched efficiency. India’s gift to the global AI era.

## Compiler Front-End Status

The C++20 package is **version 0.9.8 (pre-release)**. The documented front-end v1/API catalogue is **100% complete (40/40 items)**, and the textual LLVM IR generator lowers **100% of documented single-file front-end v1 constructs**. Together, these complete the requested front-end + IR milestone within its stated scope. This does not claim that every feature is integrated into source syntax: module/import/overload resolution are tested library APIs not wired into the single-file parser, analyzer, or CLI, and the HIR symbol index is not an LSP server. Runtime helpers, machine code, linking, execution, and tensor operations remain outside scope. LLVM is not downloaded, vendored, or built. The grammar contract remains version 1.0.0; AST and typed-HIR JSON use schema version 2, while diagnostic JSON uses schema version 1.

# indicode
ndiCode is an AI-native programming language built in India. It bridges traditional logic with machine learning, empowering developers and researchers to build high-performance AI and computational biology systems with unmatched efficiency. India’s gift to the global AI era.

## Compiler Front-End Status

The C++20 front-end package is **version 0.9.8 (pre-release)**. **Front-end feature implementation is 100% complete for the defined v1/API catalogue (40/40 items),** with the separate weighted readiness estimate at **97.25% (rounded to 97%)** because broader conformance, release/CI and compatibility work remain. The 40/40 count does not mean every feature is integrated into source syntax: module/import/overload resolution are tested library APIs not wired into the single-file parser, analyzer, or CLI, and the HIR symbol index is not an LSP server. A separate initial textual LLVM IR generator milestone is implemented for a limited scalar subset; it does not use or download LLVM, generate machine code, execute programs, or provide tensor/device backends. The grammar contract remains version 1.0.0; AST and typed-HIR JSON use schema version 2, while diagnostic JSON uses schema version 1.

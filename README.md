# indicode
ndiCode is an AI-native programming language built in India. It bridges traditional logic with machine learning, empowering developers and researchers to build high-performance AI and computational biology systems with unmatched efficiency. India’s gift to the global AI era.

## Compiler Front-End Status

The C++20 front-end package is **version 0.9.8 (pre-release)**. Code review of the 40-item front-end catalogue (IDs 445–484), its implementations, and focused tests found all 40 items present at their stated API/v1 acceptance level. The weighted front-end readiness estimate is **97.25% (rounded to 97%)**, not 100%; full language conformance, release/CI and compatibility work remain. The 40/40 count is not a claim that every feature is integrated into the source language: module/import/overload resolution are tested library APIs not wired into the single-file parser, analyzer, or CLI, and the HIR symbol index is not an LSP server. This project is a compiler front end, **not a complete compiler**: it does not generate LLVM IR or machine code, execute programs, or provide tensor/device backends. LLVM is not downloaded, vendored, or built. The grammar contract remains version 1.0.0; AST and typed-HIR JSON use schema version 2, while diagnostic JSON uses schema version 1. A fresh Release build passes all 23 CTest tests.
